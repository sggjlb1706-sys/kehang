新手 · 分步操作
  1. 明确JDK目录

    填写JDK根目录，例如 C:\Program Files\Zulu\zulu-21，里面应同时有bin/java.exe和bin/javac.exe。JRE或编辑器不等于JDK。

  2. 核对同一套工具

    采集器只用这份JDK中的java/javac，核对版本与运行身份，不从PATH借另一编译器。固定源码在自己新建的临时目录编译运行，不写入本人项目。

  3. 定位失败

    工具缺失先确认目录；版本不符按任务范围手动准备；编译或运行错误先展开原始退出码和输出。处理后同一JDK复检。
