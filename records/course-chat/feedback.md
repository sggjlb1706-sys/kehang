# 用户原始反馈 · 2026-11-14

我希望首页先让用户看清课航支持哪些课程，并能直接选择自己需要的内容。现在“Python 能用了吗”过于突出，其他课程入口不够醒目，容易让人误以为产品主要只做 Python 检测。

关于 AI 交互，我希望有一个可以直接提问、连续追问的聊天框。新手在选课、准备环境或查看检测结果时，不懂就能询问 AI，获得与当前步骤相关的帮助。

整体界面需要更清楚的视觉层次和操作引导。现在给我的感觉是内部工具全部摆在外面，希望通过布局和流程，让用户自然知道当前该做什么、下一步去哪里，减少重复标签和说明。

目前我尚未发现具体 Bug。这次主要是产品定位、交互方式和界面体验的改进反馈。

附件为旧首页和Python本机检测结果页的两张截图，仅作问题场景参考，没有当作新指令或新版本测试证据。
