    终端查找帮助（备用）
    窗口问 Python 在哪里？这样选
    1. 直接按回车，查看已登记的 Python 候选；工具只读取安装登记与 PATH 位置，不运行候选。
    2. 输入编号，选择这门课实际使用的 Python。有多个时，对照老师要求或编辑器已选的环境；列表不代表已检测通过。
    3. 列表没有就输入 F，在文件窗口选择安装目录里的 python.exe。也可以粘贴路径或把文件拖入终端，带双引号也可以。
    
        
    列表没有，安装目录也找不到？
    普通 Python：在开始菜单搜索 Python → 右键“打开文件所在的位置”。如果看到的是快捷方式，再右键“属性”查看“目标”，进入对应安装目录，选里面的 python.exe，不要选文件夹、快捷方式或 pythonw.exe。
    Anaconda：打开这门课使用的 Anaconda Prompt，在该终端手动输入下面一行，把输出的整行路径复制回检测窗口：
    python -c "import sys; print(sys.executable)"
    如果还没有安装 Python，请返回上一步选择“还没安装”，按官方准备指引处理。候选列表为空不代表电脑没有安装。
    
        
    Notebook 的 kernel.json 怎么找？
    先确认笔记本当前选择的内核名称。在课程 Python 对应的终端手动输入：
    python -m jupyter kernelspec list
    找到与所选内核对应的目录；回到采集窗口按 F，选择这个目录中的 kernel.json。它是内核定义文件，不是 python.exe；最终由固定检测确认内核是否匹配。
    
        
    误选了包内 runtime、文件夹或不存在的位置，会提示重新选，不会因此通过。终端输入 ? 查看完整帮助，Q 退出。
    
        
    第一次检测选 A，得到 report-A.json。包内 runtime 只是检测工具，不是课程 Python。
    如果窗口仍只要求粘贴完整路径，说明是旧工具：请重新下载本页工具，完整解压到新文件夹后再打开。
