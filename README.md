# 课航 · 新手分步引导版

首次打开先看到“开始 Python 基础”，也可以选择其他课程、进入 Notebook ＋ SQLite 实训，或导入老师的课程。课程按“选择课程 → 准备环境 → 运行检测 → 查看与复检”逐步展开，每次只显示当前步骤。“上一步 / 下一步”保持在页面底部可见，教师发布与核对放在独立工作台。

检测步骤只突出当前课程的检测工具；课程包、任务快照、离线指导按用途收起。点击下一步只推进界面，不会把未检测的环境标为通过。13类课程原任务与确定性规则继续沿用。

## 在已有 Windows 环境中启动

完整解压，进入有 `campuslab`、`web` 和 `vendor` 的根目录。网页服务使用已有 Python 3.10 或以上，只有标准库依赖。本机已核验的解释器为 `D:\ANACONDA\python.exe`。其他电脑将下一行的解释器替换为自己的绝对路径，也可使用已配置的 `python`。

```powershell
& 'D:\ANACONDA\python.exe' -B -m campuslab.web --port 8786 --database '.\data\guided.sqlite' --runtime-zip '.\vendor\python-3.13.17-embed-amd64.zip'
```

打开 http://127.0.0.1:8786/ 。端口被占用时换一个空闲端口，并用相同端口访问。按 Ctrl+C 停止本次服务。上面的路径会创建专用课程库。为演示教师与学生分别启动两个实例时，第二个实例请同时改端口和数据库文件名。

## 用一堂课复核产品

1. 首页“跟做一堂数据分析实训”，按四步了解任务、准备环境、跟做、提交。教师从右上“教师工作台”发布并导出；学生从首页“老师已经发了课程资料？”导入。
2. 第三步下载资料，完整解压至新目录。打开随包 Notebook，选择课程内核，填写三个统计表达式并运行。用同一份 CSV 按模板填写分组 SELECT，运行 SQLite 练习，得到 `实训成果.json`。
3. 第四步选成果、核验并导出完成物。教师在工作台“核对学生完成物”逐次重算。环境探针、阅读声明和提交数值分别记录。
4. 实训第二步可进入 Notebook / SQLite 环境向导，并用顶部“返回实训”继续。Python / Notebook 下载工具后双击 `Start-Collect.cmd`，确认实际目标和 A/B；SQLite 需用练习生成的 scores.sqlite。初检 A 后，从结果页“去采集复检报告”进入 B，再导入单份 B 会保留 A；也可一次选择两份原始报告。

**十分钟启动的前置**是已有 Python 和可用浏览器。要在该时间内演示计算，还需已有 Jupyter、受支持的 ipykernel、NumPy、Pandas 和匹配的内核定义。版本及开发工具见 `DEPENDENCIES.md`。本机练习不需账号、模型或密钥；`.env.example` 为自愿使用 AI 诊断时的进程环境变量模板。
