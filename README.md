# 课航 · 课程首页与 AI 连续对话

首页直接展示现有13类课程，按基础编程、数据分析、AI与深度学习、系统环境筛选。点击课程进入对应准备步骤；Python一键检测位于Python课程内。连续实训、教师课程导入和教师工作台保留独立入口。

右侧“课航AI”支持直接提问和连续追问。当前课程、步骤、有效报告和近期对话会组成脱敏发送预览；检查目的地和内容后，点击“同意并发送这条”。同课程跨步骤保留对话，切换课程分别保留聊天与草稿；刷新即清空。每次最多携带最近10轮，预览10分钟有效且只能发送一次。发送失败保留问题，不伪造AI回答。

AI是可选连接，复用`.env.example`中的服务进程变量。`CAMPUSLAB_AI_URL`填写兼容Chat Completions的完整请求地址，`CAMPUSLAB_AI_MODEL`填写模型名；认证凭据仅放终端的`CAMPUSLAB_AI_KEY`。设置后重启服务；该示例文件不会自动加载。远程地址需HTTPS，本机服务可用127.0.0.1或localhost的HTTP。未配置时会显示“尚未连接模型”，课程指引、检测和实训仍可使用。本轮未调用真实或收费模型，聊天验收使用明确标记的本地协议夹具。

结果页先显示结论和下一步；通过后的明细、环境选择与原始报告按需展开。失败明细仍展开。所有课程规则、Python固定检查范围及原Windows11图示沿用。当前验收见`docs/课程首页与连续对话验收.md`，独立审查见`REVIEW.md`。

## 在已有 Windows 环境中启动

完整解压，进入有 `campuslab`、`web` 和 `vendor` 的根目录。网页服务使用已有 Python 3.10 或以上，只有标准库依赖。本机已核验的解释器为 `D:\ANACONDA\python.exe`。其他电脑将下一行的解释器替换为自己的绝对路径，也可使用已配置的 `python`。

```powershell
& 'D:\ANACONDA\python.exe' -B -m campuslab.web --port 8787 --database '.\data\local-check.sqlite' --runtime-zip '.\vendor\python-3.13.17-embed-amd64.zip'
```

打开 http://127.0.0.1:8787/ 。端口被占用时换一个空闲端口，并用相同端口访问。按 Ctrl+C 停止本次服务。上面的路径会创建专用课程库。为演示教师与学生分别启动两个实例时，第二个实例请同时改端口和数据库文件名。

## 用一堂课复核产品

1. 首页“跟做一堂数据分析实训”，按四步了解任务、准备环境、跟做、提交。教师从右上“教师工作台”发布并导出；学生从首页“老师已经发了课程资料？”导入。
2. 第三步下载资料，完整解压至新目录。打开随包 Notebook，选择课程内核，填写三个统计表达式并运行。用同一份 CSV 按模板填写分组 SELECT，运行 SQLite 练习，得到 `实训成果.json`。
3. 第四步选成果、核验并导出完成物。教师在工作台“核对学生完成物”逐次重算。环境探针、阅读声明和提交数值分别记录。
4. 实训第二步可进入 Notebook / SQLite 环境向导，并用顶部“返回实训”继续。Python / Notebook 下载工具后双击 `Start-Collect.cmd`，确认实际目标和 A/B；SQLite 需用练习生成的 scores.sqlite。初检 A 后，从结果页“去采集复检报告”进入 B，再导入单份 B 会保留 A；也可一次选择两份原始报告。

**十分钟启动的前置**是已有 Python 和可用浏览器。要在该时间内演示计算，还需已有 Jupyter、受支持的 ipykernel、NumPy、Pandas 和匹配的内核定义。版本及开发工具见 `DEPENDENCIES.md`。本机练习不需账号、模型或密钥；`.env.example` 为自愿使用 AI 诊断时的进程环境变量模板。
