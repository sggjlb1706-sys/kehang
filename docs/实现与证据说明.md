- rules.py：任务内容摘要、完整事实校验、确定性判断和同目标比较，所有入口共用。
- collect.py/probe.py：本人手动启动，在显式目标解释器内读取包版本与固定运行结果；网页不代跑。
- courses.py/web.py：SQLite每次发布新码和不可变快照；仅监听127.0.0.1，拒绝非本机Host与跨来源请求，不做公网或跨设备可达声明。

## 实际问题及修正

1. SQLite上下文只结束事务而未关闭连接，Windows测试清理失败；增加显式关闭，失败日志保留iteration-2。
2. AI协议测试清空全部进程环境，影响Windows证书环境；改为只覆盖本测试的AI配置，本机HTTP接口直连，不更改系统代理。该失败不是外部模型服务故障。
3. 浏览器自动等待表达式触发CSP的eval限制；将测试改为函数，不放宽产品CSP。
4. 课程链接自动提交无submitter时按钮为空，导致课程未加载；修正按钮状态处理，真实Edge重新验证课程链接。
5. Edge内部下载页资源原被测试误算成外网请求；区分浏览器内部edge:与真正http(s)外部请求，保留原失败结果。
6. 独立审查发现弯引号路径导致PowerShell解析失败，修正路径字面值编码，实际复杂目录与9组逐字符往返测试均作为新回归依据。旧候选和阻塞报告保留。
