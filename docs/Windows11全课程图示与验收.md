# Windows 11 全课程图示

用户要求其他课程也有图示，并指出上一版简陋、与Windows 11页面不像。本轮保留上一正式版及58提交，在新分支改引导展示与必要的旧路径清空，不重写课程或规则。

图示采用标签页、地址/搜索栏、命令栏、常用位置、文件详情列、蓝色选择和快捷方式属性窗口，终端使用Windows Terminal式外观。步骤按钮切换画面，“去填写对应位置”定位本页真实表单。图内没有执行接口，不自动填示例，不把步骤浏览当通过。日期为占位，不伪造本机文件时间；所有图标和画面由本版HTML/CSS自制，实际文件以本人窗口为准。不同Windows构建布局可能略有差异。
