## 共同原则

- 先明确假设、范围和可验证结果；最小实现、必要改动，不顺手重构。
- 目标解释器、未知/失败、固定快照及复检必须真实。样例、协议模拟、本机PATH隔离不能冒充真实设备或模型结果。
- 检测只读；工具自带Python不是课程Python。产品不自动安装、运行建议命令、修改系统/网络或部署公网。
- AI只解释已有证据；预览/编辑发送内容、披露目的地并经用户勾选同意后才发。密钥由本人安全输入，不读取旧进程或保存到文档。
- 历史证据、已运行、失败和未运行分别记录；清理过的测试venv不得继续当可用环境。
- 独立审查者只读复核固定文件与SHA，可运行必要非破坏性检查，不修改实现。主执行者处理有证据的问题。
