# 新手分步引导版：改动与验收

2026-11-11。承接实训交付451d7b9。用户反馈原文与两张原图副本在records/guided/feedback；用户明确指出首页让初学者不知从何下手、下载项不知选哪个，希望一步完成再进入下一步。

| 真实问题 | 本轮行为 | 验证 |
|---|---|---|
| 首页同时出现实训、环境、上传等功能 | 首页仅推荐开始Python，保留其他课程、实训和老师资料入口；无上传或下载表单 | 首页截图、DOM可见性检查 |
| 下载按钮并排，不知用途 | 当前检测步骤只突出一项工具下载；快照收在任务详情，课程包/离线资料收在分享区，教师可直接导出 | 实际下载ZIP、任务身份、教师无报告即可导出并导入 |
| 很长一页，缺少下一步 | 课程四步、当前阶段单独展示；底部上/下一步随页面保持可见 | 390/768/1360px、键盘、实际按钮位置检查 |
| 界面前进容易被误当成通过 | 无有效报告不能进入结果；只浏览准备不生成通过；初检和复检单独表述 | 分享副本拒绝、真实A/B重算、三模式事实一致 |
| 反复搬报告 | 初检后“去采集复检”选择B，导入单份B保留A；两份一次选取兼容 | 真实Python A/B，时间/身份比较 |
| 实训与环境之间容易丢失方向 | 实训另分四步，组件向导有返回实训；教师发布/重算分开 | 实训材料ZIP、错误41→正确42、完成物教师重算 |

源程序的课程、规则与成果服务未修改。新界面测试脚本为tools/verify_guided_ui.py，结果分别保存于records/guided的独立时间目录，失败不覆盖成功。最终通过目录以acceptance.json为入口。10组浏览器检查覆盖13类课程、原教师包、坏包清理、异步导航、390/768/1360px、键盘及文字对比度；现有134项单测另存unit-final.txt。

首轮脚本尝试在结果页直接选择隐藏在准备页的说明模式，随后浏览器退出回调作用域也不正确；这两项是验证脚本错误，已调整，原失败记录保留。执行者逐屏复核还发现长页下一步不可见、切课继承B阶段，两项均先留下真实失败检查再修正；它们由执行者发现，不冒称用户逐项报告。

这是本机代理操作，报告使用上一版真实采集的原件重新分析；未在本轮重新运行全部课程环境或取得独立新手成效。原用户反馈与本轮响应、差异和验证可以作为真实UI迭代的证据，仍需本人实际审阅，不自动认证三条完整核心Prompt链。

继承的PDF/MP4保留上一版UI语境，本轮交付的是新的可运行界面与截图。独立审查及最终实物摘要见REVIEW与仓库外新交付回执。没有公开、推送、上传、模型调用或DSH授权运行。
