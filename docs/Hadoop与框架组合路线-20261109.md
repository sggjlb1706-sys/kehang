# Hadoop、Agent框架与MCP的组合准备路线

核对日：2026-11-09。此页提供有来源的准备与逐组件验收设计，**没有实现Hadoop集群采集、启动或作业执行**。新Java/Notebook/SQLite任务各自通过，也不能使本页组合课程通过。

## 先固定Hadoop版本与运行方式

Apache[发布页](https://hadoop.apache.org/releases.html)本次列出3.5.0（2026-04-02）、3.4.3等版本；本页以[3.5.0单节点官方指南](https://hadoop.apache.org/docs/r3.5.0/hadoop-project-dist/hadoop-common/SingleCluster.html)为来源示例。`/docs/stable/`本次实际打开的是3.3.5，不能把该别名当作当前最新版本或套用不同版本的命令。版本仍由教师指定；本人核对发行包来源和校验文件后再准备，本产品不会下载/安装。

官方指南区分Standalone、Pseudo-Distributed与Fully-Distributed。Standalone是单Java进程的本地练习，不证明HDFS/YARN或多节点集群可用；伪分布式同样不等于多台机器。Linux是指南的支持平台。使用官方远程daemon管理脚本时，需要相应SSH/sshd；不能从Windows存在ssh.exe推断Linux来宾的SSH已经配好。

Java须按目标Hadoop分支核对。[Apache Hadoop Java Versions](https://cwiki.apache.org/confluence/spaces/HADOOP/pages/100827883/Hadoop+Java+Versions)当前明确3.5及以上的服务端要求JDK17，客户端支持JDK17/JDK21。现机Zulu JDK21的Java固定课通过只证明该Windows目标能编译运行本课程源码，不能据此判Hadoop服务端依赖满足；Windows的JDK也不能代替Linux来宾内的JAVA_HOME。

## 本项目拟采用的逐组件验收

下表为本项目的验收设计，并非声称Apache已有对应Windows检测器。

| 层 | 必须固定的身份 | 本人准备及可核对证据 | 缺失时的状态 |
|---|---|---|---|
| 教师任务 | Hadoop版本、模式、JDK、实验目标 | 课程明确Standalone/伪分布式/多节点，不能临时降级替代 | 未定要求先澄清 |
| Linux来宾 | 宿主/VM UUID、来宾DMI与machine-id摘要 | 由本人启动现有VM并手动取得同实例来宾报告 | 当前未取得，未知 |
| 来宾Java | Linux JAVA_HOME、java/javac、版本与实际home | 在该来宾核对对应分支要求；不要借Windows JDK或其他PATH条目 | 当前未知 |
| SSH | 目标主机、端口、host key、当前本人账号 | 本人核对主机身份并按课堂要求连接；不采私钥/密码，不自动改authorized_keys或网络 | 当前未验证 |
| Hadoop安装 | 发行版本/校验、HADOOP_HOME、配置摘要 | 明确bin路径及JAVA_HOME；不把命令可见当作集群已运行 | 当前未知 |
| HDFS/YARN | 集群ID、NameNode/ResourceManager和允许节点 | 在本人已运行的实验集群取对应只读状态；不能用单机Java成功替代 | 当前无集群证据 |
| 固定作业 | 输入文件/摘要、JAR版本、输出专用目录、作业ID | 准备条件满足后再由本人明确授权，在新目录运行固定小例并核对输出和时间 | 本轮未运行 |
| 复检 | 同一快照和以上全部身份 | A/B时间递增；换来宾、JAVA_HOME、集群或配置形成新目标/新任务 | 无证据不能通过 |

最小后续练习可以采用官方Standalone示例中随发行包提供的MapReduce examples JAR，绑定版本并在新输入/输出目录验证固定结果；它写入输出文件，必须在本人确认的专用练习目录单独执行。升级到HDFS/YARN时另取得集群身份和对应实际作业，不能把本地结果移作分布式通过。本轮未运行格式化、daemon启动、SSH写配置或该作业。

本轮已有实证：`records/reuse-ai/java/`的Zulu21固定编译/运行；VMware软件与来宾未知边界见既有`records/courses/vm/`及本轮最终VM回归。它们并不提供Linux来宾内JDK、SSH或Hadoop集群证据。当前最少外部条件是教师固定要求、本人已有并启动的Linux来宾/集群，以及允许的来宾Java/SSH环境；其余可独立开发的课程不以这些条件为前提。

## Agent框架与MCP

DeepSeek Harness是本轮已实现独立课程，桌面/CLI、模型、权限和实际工具证据分层。Dify是工作流平台候选，当前不采用其代码或部署；不能以DSH课通过宣称Dify工作流已支持。

[MCP固定版规范2025-11-25](https://modelcontextprotocol.io/specification/2025-11-25)说明Host/Client/Server和JSON-RPC能力协商；它是工具互通协议，不是某模型或Agent任务成功证明。后续如建设MCP课程，应先固定本地服务器源码、依赖与协议版本，只暴露一个已审查的只读演示数据工具，明确参数/根目录，分别记录连接协商、模型提出工具调用、执行器实际结果和本人授权。仅手工构造JSON-RPC消息属于协议验证。本轮未实现或启动MCP服务器、未添加任意命令执行入口；此项保持来源路线。
