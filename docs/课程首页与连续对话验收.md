# 课程首页与连续对话 · 2026-11-14

本轮依据用户的产品与交互反馈，在D盘开发工作区现有仓库实现；分支为`codex/kehang-course-chat-20261114`。用户没有报告具体Bug。未改写旧D盘原项目、versions或submission；C盘路径仍只是Junction入口。

## 当前行为

- 首页同层级展示13类课程，支持按方向筛选，点击直接进入对应准备步骤；保留实训、教师资料导入和教师工作台。
- Python一键检测移到本课程准备步骤，使用当前任务身份与要求，包括教师自定义版本范围。其他课程继续沿用手动固定检测与原图示。
- 聊天可直接提问和连续追问；同课程跨步骤保留记录，切换课程分别保留对话和草稿。选课屏单独保留选课会话，不带上一门课的报告。
- 每轮服务端重算有效报告、组合当前步骤与近期对话并脱敏；展示目的地和内容后，由用户单次同意。票据10分钟有效、一次消费，最多保留32份待发预览。修改问题或步骤会撤销页面预览；迟到响应不写入其他课程。
- 未配置AI时可以编辑问题和检查上下文，发送按钮不可用，显示连接说明；失败保留问题，不生成虚假回答。设置方法见README和`.env.example`。
- 结果先呈现结论与下一步，通过后的明细、环境列表及原件按需展开。宽屏聊天与步骤并列，窄屏主动展开，缩屏后收起；小屏预览可滚动，顶部收起保持可见。

## 发现与修正

浏览器首先发现宽屏缩小时聊天遮挡课程操作，已增加收起。整页截图曾短暂把视口设为1×1，误触收起；稳定200ms后再判断当前视口解决了该问题。

独立只读代理对固定候选`418b9cb`发现：Python准备页快捷按钮仍沿用旧首页默认任务加载，可能覆盖老师要求；选课第0步仍携带旧课程与报告。前者改为直接检测当前任务，后者使用独立选课上下文，均补充真实浏览器回归。审查同时提示的小屏预览滚动可达性已修正并在390×700核对。

早期本轮运行记录保留在本仓库`data/course-chat-debug`，最终复核以上述通过记录为准。未运行真实收费模型、未部署公网、未上传参赛材料。本轮没有新发布ZIP；原交付包仍对应各自历史版本。
