# 一键本机检测

用户反馈终端的候选编号/路径选择仍麻烦，并在本次澄清中明确选择“改成课航内一键本机检测”。本版在完整路径引导基线之后独立推进，不重做课程或实训。用户要的是省去查找路径、终端确认和搬运JSON；实现入口使用固定检测助手，AI解释保留单次预览同意。

首页“检测本机Python” → 自动发现登记/PATH候选 → 固定检查 → 页面展示每个环境结果。已有Python基础任务可在检测步骤点击同一入口；教师自定义版本要求仍用原快照判定。多个环境分别列出，初次默认展示首份有效报告，并不证明它是编辑器或老师选中的环境。其他课程保留手动流程。

点击前不发现或运行候选。服务只监听127.0.0.1，每个实例有随机令牌；Host/Origin和令牌共同校验，POST只接受固定任务、true同意及服务生成的复检编号。网页不能提交目标路径、命令、脚本或进程号。固定包装器使用私有Windows Job，收到父进程握手后才采集；取消、超时、服务关闭会清理本次进程树，不查杀其他Python。页面无心跳15秒后取消。检测最多8个候选，一次一个任务；最近8个任务保留在服务内存。

检测报告由原collect/probe产生，父服务再次按原analyze校验；复检从服务保存的环境身份解析目标，并用compare核对原始基线和时间。未知、目标冲突或缺少报告均不能通过。内置工具运行时排除。相同路径上的软件被删除后仍复检原目标，不替换为另一个Python。AI按钮只建立预览，不代替规则、不自动发送。

原先：下载ZIP、解压、打开终端、列候选/选路径、确认START、运行、导入报告。现在：主页点击一次，等待真实结果；需要时点击当前环境复检。另一台电脑、未登记环境及其余课程仍可展开手动工具。

本轮验证入口为records/local-check/acceptance.json，里面指向真实A/B原件、7组针对性浏览器验证、13组兼容浏览器验证和单测日志。浏览器失败文件和执行记录摘要分别保留：第一次新浏览器脚本退出栈顺序错误；taskkill无法在受限启动环境清理子进程，替换为Job后通过；新首页高度暴露迟到错误通知导致滚动的问题，错误提示加导航身份约束后通过；旧键盘测试等待的第一步已改为新入口行为，手动入口和一键入口分别验证。没有修改验收结论来掩盖失败。

真实A/B是同一台电脑的代理操作，不证明独立新手可用性；控制多环境、无候选、慢响应等是构造场景。没有实际模型调用、安装或自动修复，没有补造三条完整Prompt链。继承PDF/MP4仍是历史界面。本轮独立审查和交付信息见REVIEW.md与新仓库外交付回执。
