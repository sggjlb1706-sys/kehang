## 代表采集路径

以下两条路径均以下载包内有已核验的 Python 嵌入运行时为前提。下载、完整解压、本人确认目标、采集A和较晚B仍需实际完成。

| 操作 | 原正式版高级命令入口 | 新版包内入口 |
|---|---|---|
| Python基础需手填的路径 | 工具目录、课程Python：2项；工具Python在此条件下可空 | 课程Python：1项；工具目录、task.json及runtime由主动启动的入口定位 |
| Notebook需手填的路径 | 工具目录、课程Python、kernel.json：3项；工具Python可空 | 课程Python、kernel.json：2项 |
| A/B阶段选择 | 网页选择初检A或复检B，重新生成相应命令 | 终端明确输入A或B |
| 开始前确认 | 本人核对生成的多行命令，再到终端运行 | 终端展示任务全摘要、目标和输出，必须主动输入 `START` |
| 完整A/B需搬运的命令 | 分别生成并复制运行A、B：2个多行命令块 | 双击包内 `Start-Collect.cmd` 两次：0个复制命令块；仍需本人输入目标与确认 |
| 导入A/B的文件选择动作 | 分别选择A和B：2次 | 一次多选两份原始报告：1次，按内容时间核对先后 |

新版不把已有PATH或工具runtime猜成课程目标，不扫描机器，不增加网页执行接口。Python/Notebook之外的类型继续保留原高级命令入口；没有包内runtime时也使用高级入口选择已有工具Python。新入口遇到原报告存在时拒绝覆盖，新一轮应解压至新目录。

## 报告核对与下一步

一次选取入口仍调用既有 `/api/analyze` 和 `/api/compare`。既有组件身份（例如Notebook内核、SQLite文件/工具运行时、DSH工作区/模型）分别核对；不按文件名排序。只有单份报告时作为初检导入。两份时间相同、混合目标、其他任务、脱敏分享副本或无效数据不能沿用旧成功。分别导入A/B的兼容入口仍保留。

实训区分三条状态：环境固定探针、本人阅读声明、限定成果核验。教师发布/学生导入后，Notebook和SQLite有各自课程任务和环境报告。学习目标、每步应看到什么及恢复办法集中在可展开的实训步骤中；提交结果提供明确的重新计算/重新提交办法。

完成物保留每次实际核验记录，限定格式之外的上传内容不写入导出，只保留摘要与拒绝原因，避免任意额外字段传播。教师可在“教师核对学生完成物”中重新核验保留的限定数据成果；文件原先的 `passed` 不能让错误结果通过。格式无效或旧资料的原内容需另取原件核对。同任务同数据的正确结果不能证明未复制、实际操作或学习掌握。
