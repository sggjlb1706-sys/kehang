# 课程调研与产品能力范围（2026-11-08）

## 产品范围及本轮先后

产品面向计算机及数据相关专业的实验环境，包括编程/软件开发、数据分析与Notebook、数据库/SQL、机器学习与深度学习、Linux/操作系统与虚拟化、Java及分布式大数据、网络/云计算等方向。课程目录可以收录候选，但“列入调研、提供指导、实现采集与验证、真实设备实测”是四种不同状态。

当前正式版有Python、Node.js/npm示例及固定Qwen任务。下一轮建议优先交付两个可运行闭环：

1. **PyTorch示例课程**：明确选定Python环境，检查PyTorch及其版本，执行固定CPU张量运算；课程需要GPU时另核对框架构建、可用设备并由本人明确触发固定GPU运算，不能用CPU成功替代GPU成功。Notebook内核关联作为适用该课程时的独立证据。
2. **虚拟机/Linux示例课程**：明确选定支持的虚拟化软件、虚拟机实例及来宾证据来源；分别展示宿主虚拟化、工具、实例、来宾系统和课程验证状态。只发现虚拟化软件不能宣称来宾系统或课程通过。来宾不可访问就保留未知，不自动安装、下载镜像、创建/启动虚拟机或修改BIOS、系统和网络。

这两个闭环应通过同一任务快照、报告、确定性规则、指导及复检框架体现不同环境类型；现有Python、Node、Qwen及教师任务的旧快照和报告要保留兼容。多组件环境的身份不能压缩成一个与其无关的可执行文件路径，例如Python解释器与GPU、宿主机与虚拟机实例/来宾系统应分别核对。

Java/JDK、数据分析/Notebook、数据库、Hadoop等方向应进入带来源的候选目录，并根据已有环境、验证条件与11月18日15:00截止时间确定本轮可真实完成的模板；未完成的部分不得显示为可自动检测或已经实测。产品目标不限于这两个先行示例，但也不能把培养方案出现的每门课都冒称已支持。

## 功能验收边界

共同能力包括：需求澄清、受支持的课程模板、老师固定任务、显式目标与多组件身份、部署前证据、分层指导、手动采集/修复、四状态、同任务同目标复检、可编辑脱敏预览及经同意的AI诊断。老师任务可携带及手机看指导仍需补齐；无需班级、成绩、账号后台或自动安装。

课程模板配置应受支持的固定检测类型和已审查的执行边界约束；未知模板不得通过导入而执行任意代码。AI只解释已有证据及提出可审查的步骤，规则结论由确定性程序生成。任何新增能力按可验证纵切落地，不把后续UI阶段或材料收尾提前当作产品能力完成。
